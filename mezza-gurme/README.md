# Mezza Gurme — цифровое меню

Новое QR-меню для ресторана **Mezza Gurme** (Аланья). Оно сохраняет фирменный стиль ресторана (тёмно-изумрудный фон, бирюзовый и золотой акценты, шрифты Cormorant Garamond и Inter, рукописный логотип), но сделано как современное мобильное приложение.

Всё меню на месте: **312 позиций, 25 категорий, 5 языков (TR, EN, RU, PL, DE), 273 фотографии блюд**. Данные взяты с текущего сайта mezzagurme.com.

## Что умеет

- **Одна прокручиваемая страница** вместо «категория → назад → категория». Липкая лента категорий подсвечивает текущий раздел. Кнопка-сетка открывает все категории плитками с фото.
- **Поиск по всему меню сразу на всех языках.** Турист может набрать «muhlama» или «мухлама» и найдёт блюдо в любом случае. Можно ограничить поиск разделом (завтраки, бар…) или показать только блюда из полбы на закваске.
- **Карточка блюда:** большое фото, полное описание, название по-турецки (чтобы показать официанту), аллергены, пометка «Полба · закваска» с объяснением, кнопка «Поделиться».
- **Объёмы напитков сведены в одну карточку:** например, Yeni Rakı 20/35/50/70/100 cl вместо пяти одинаковых строк. Было 312 строк, стало 275 карточек.
- **«Мой выбор»** — гость собирает список с количеством и видит итоговую сумму. Кнопка **«Показать официанту»** открывает светлый крупный экран **на турецком** с номерами позиций и номером стола. Работает при любом языке гостя.
- **Заказ доставки через WhatsApp:** готовое сообщение с позициями и суммой на номер ресторана.
- **Часы подачи:** завтраки помечены «Подаётся 08:00–13:00». Вне этого времени они приглушены и уходят в конец меню, поэтому вечерний гость начинает сразу с закусок и горячего.
- **Номер стола из QR** (`?table=12`) — показывается в шапке, в списке и на экране для официанта.
- **Язык подбирается автоматически** по языку телефона, его можно переключить, выбор запоминается.
- Два вида меню: **список** или **плитка** с крупными фото.
- **Работает офлайн** (service worker): при плохом Wi-Fi в зале меню открывается из кэша. Можно добавить на экран телефона как приложение (PWA).
- Адаптив от 320 px до десктопа: на большом экране слева появляется боковое меню, карточка блюда открывается в двухколоночном окне.
- Доступность: проверено axe-core, нарушений 0. Работает с клавиатуры и экранных читалок, учитывает `prefers-reduced-motion`.

## Как посмотреть

```bash
cd mezza-gurme
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно открыть и просто `index.html` двойным кликом. Не будет только офлайн-режима, ему нужен http(s).

Полезные ссылки:

| URL | Что делает |
|---|---|
| `/?lang=ru` | открыть на нужном языке (`tr`, `en`, `ru`, `pl`, `de`) |
| `/?table=12` | меню для стола №12 |
| `/#i32` | сразу открыть блюдо №32 (Мухлама) |
| `/#c-pizzalar` | сразу перейти к категории |
| `/qr/` | генератор QR-табличек для столов (A4, 4 на лист, печать) |

## Как опубликовать

Это обычная статика без сервера и базы данных. Её можно положить на любой хостинг.

- **GitHub Pages:** Settings → Pages → Deploy from a branch → выбрать ветку и папку `/ (root)`. Меню будет по адресу `https://<user>.github.io/<repo>/mezza-gurme/`.
- **Netlify / Vercel / Cloudflare Pages:** перетащить папку `mezza-gurme` в Netlify Drop.
- **На их домене:** положить папку, например, в `mezzagurme.com/qr-menu/` и перенаправить на неё старый QR-адрес `/ru/menu?qr`.

## Как обновлять меню

Ресторан продолжает работать в своей нынешней админке, вводить данные заново не нужно. Скрипт забирает свежее меню с их сайта на всех 5 языках, применяет исправления и пересобирает данные и фото:

```bash
pip install pillow
python3 tools/sync.py
```

Скрипт:
- обновляет `data/menu.js`;
- докачивает новые фото и делает для них превью;
- удаляет фото, которые больше нигде не используются.

Его можно запускать по расписанию, например через GitHub Actions раз в час.

Ручные правки лежат в `tools/overrides.json` (сам `data/menu.js` вручную не редактируется):
- `featured` — блок «Выбор шефа» (номера блюд и бейджи `star` / `popular`);
- `items` — исправления переводов и описаний по номеру блюда;
- `replace` — автозамены опечаток во всех языках;
- `variantCategories` — в каких категориях объединять объёмы;
- `contact` — телефон, WhatsApp, Instagram, часы работы.

Тексты интерфейса для всех языков находятся в `assets/js/i18n.js`.

## Структура

```
index.html            разметка и SVG-иконки
assets/css/           стили (main.css) и локальные шрифты (fonts.css)
assets/js/app.js      вся логика, чистый JS без зависимостей
assets/js/i18n.js     тексты интерфейса на 5 языках
data/menu.js          меню (генерируется tools/sync.py)
photos/               фото блюд 700 px + превью 480 px (photos/s/)
qr/                   генератор QR-табличек (qrcode-generator, MIT)
sw.js                 офлайн-кэш
tools/                синхронизация с сайтом ресторана и ручные правки
```

## Что исправлено относительно текущего меню

Скрипт сборки автоматически исправляет следующее:
- Позиции, которые не были переведены: эвкалиптовый, лавандовый и фенхелевый чай, содовая с лимоном. В EN/RU/PL/DE они шли по-турецки.
- Опечатки: «Тарator», «Rıvıera Gın», «Negrony», «Teqila», «Stella Artoıs», «Screamble», «mozerella / mozeralla», «baharatlarlar».
- Пробелы перед запятыми и точками, текст КАПСОМ в описаниях.
- У четырёх бутылок 70 cl состав комплекта (Red Bull, San Pellegrino, фрукты) был указан везде, кроме турецкого. Теперь он есть и в TR.
- Неправильное склонение в шапке: «25 категории» → «25 категорий». Отсутствующий пробел в «НашеМеню».

Нужно уточнить у ресторана:
- В турецком названии пицц указано «+ 1 Meşrubat» (пицца + напиток), а в остальных языках этого нет. Иностранные гости не знают про напиток в подарок.
- Аллергены заполнены не везде: у десертов и сырных тарелок их нет совсем. Поэтому фильтры «без глютена / без молока» пока не включены, чтобы не вводить гостей в заблуждение. Как только данные будут заполнены, их можно включить.
- Завтраки подаются с 08:00, а в часах работы указано 10:00–23:00.
